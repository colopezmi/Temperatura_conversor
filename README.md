# Conversor de Temperaturas

Aplicación web estática y responsive para convertir entre Celsius, Fahrenheit y Kelvin.

## Estructura

```text
conversor-temperaturas/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── app.js
└── README.md
```

## Ejecutar

Abre `index.html` directamente en un navegador moderno. No requiere instalación, compilación, backend ni base de datos.

## Desplegar

Publica el contenido de esta carpeta en cualquier hosting estático. `index.html` ya está en la raíz del proyecto.
